# Quiver — User-added Python tools
#
# Each line is installed via pipx into its own isolated virtualenv.
# Tools never share dependencies with each other or with apt packages,
# so adding a new tool here can never break an existing one.
#
# Rebuild after changes:
#   docker-compose up --build backend
#
# Usage:
#   PyPI package name:  certipy-ad
#   GitHub URL:         git+https://github.com/author/tool
#
# Finding the right name:
#   - PyPI: https://pypi.org/search/?q=toolname
#   - Kali packages (often faster): https://pkg.kali.org
#   - If it's in Kali apt, add it to user-tools.txt instead — apt is faster and conflict-free
